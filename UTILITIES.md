# Helper Utilities

This document describes the helper scripts and utilities available in the NjordDeploy repository.

## Development Scripts

* run_editor.py: Starts the metadata editor application for developers.
* scripts/fetch_assets.py: Fetches the required frontend assets.
* scripts/manual_scanner_test.py: Test utility for verifying host scanning logic.

## Platform Scripts

* linux/install.sh: Installation script for Linux systems.
* windows/start.bat: Startup batch script for Windows environments.
