# Security Policy

## Supported Versions

The table below outlines which versions of NjordDeploy are actively supported with security patches.

| Version | Supported          | Architecture        |
| ------- | ------------------ | ------------------- |
| 1.x     | :white_check_mark: | ARM, Intel, AMD     |
| < 1.0   | :x:                | None                |

## Reporting a Vulnerability

We take the security of NjordDeploy seriously. If you discover a security vulnerability, please do **not** open a public GitHub issue. Instead, report it responsibly.

Please send an email to security@njorddeploy.com with the following information:
* A description of the vulnerability and the potential impact.
* Step-by-step instructions to reproduce the issue.
* The hardware architecture and environment where it was discovered.

## Disclosure Process

After receiving your report, we will:
* Acknowledge receipt of the report within 48 hours.
* Work on a fix or mitigation strategy.
* Keep you updated on the progress and coordinate a public release date for the fix.
