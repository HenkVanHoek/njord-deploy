Components

Quick Start & Concept Guide

Welcome to the NjordDeploy Component Editor! This workspace is used to customize the software stacks running on your target server.

Components

The atomic building blocks of your system. Each represents a single self-hosted service (e.g. Pi-hole, Nextcloud, AdGuard) containing direct Docker Compose definitions, variables, and packaging rules.

Packages

Logical stacks consisting of grouped components. Perfect for designing coherent Multi-Container system architectures (like nextcloud stacks or database structures).

Macros & Variables

Inject portable properties into your compose templates dynamically. Use {% raw %}{{ CONFIG_BASE_PATH }}{% endraw %} to declare clean local file systems, and {% raw %}{{ DOTENV.YOUR_ENV_VAR }}{% endraw %} to reference global environment configs safely.

Traefik SSL Routing

Enable the "Has Traefik Support" switch to automatically inject secure HTTPS loadbalancer routing rules. No complex proxy labels are needed inside compose.

AI Component Bootstrap

Generate new components automatically via Google Gemini. Click "Create with AI" at the top of the sidebar, enter a GitHub repository URL with optional custom instructions, and Gemini will bootstrap the configuration templates, variables, and metadata.
