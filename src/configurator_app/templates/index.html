Getting Started & Prerequisites
Checklist & AI Setup
Deployment Checklist
  • Target Machine: Raspberry Pi, Orange Pi, ODROID, VM, or server running Debian/Ubuntu (64-bit recommended).
  • SSH Access: Port 22 open with sudo permissions. Key-based authentication recommended (ssh-copy-id username@target-ip).
  • Network Scanner: nmap installed locally for auto-discovery (sudo apt install nmap), or use Direct IP / Tailscale / Proxmox.
  • Container Engine: Choose Docker CE or rootless Podman via the topbar switcher.

Welcome to NjordDeploy
Self-Hosting Made Simple in 4 Easy Steps

NjordDeploy provisions and orchestrates containerized services on Single-Board Computers (Raspberry Pi, Orange Pi, ODROID), cloud/local Linux servers, and Proxmox LXC/VMs.

1. Target Discovery

Find target SBCs automatically via local L2 ARP scan, sweep custom CIDR subnets, target direct IPs / Tailscale mesh nodes, or provision new Proxmox LXCs/VMs.

2. SSH Connection

Connect securely to your target machine using SSH key authentication (ssh-copy-id) or password with standard sudo privileges.

3. Select Services

Pick from 45+ modular container stacks (AdGuard Home, Vaultwarden, Nextcloud, etc.). NjordDeploy automatically checks for port and storage conflicts.

4. Live Deployment

Watch live Ansible streaming logs, verify container status, launch your web UIs with direct links, and manage backups with the built-in backup manager.
